A terminal-first password manager with local encrypted files, automatic git history, 2FA codes, and no hosted account.

Install

Downloadable from GitHub Releases.

The installer detects macOS or Linux, downloads the matching tarball, installs the binary to ~/.local/bin, then lets NibPass add shell setup for zsh, bash, or fish. 

# latest nibpass-v* release
curl -fsSL https://raw.githubusercontent.com/nibtools/nibtools/main/nibpass/install.sh | bash

# specific release
curl -fsSL https://raw.githubusercontent.com/nibtools/nibtools/main/nibpass/install.sh | bash -s -- --version nibpass-v0.1.0

# custom binary directory
curl -fsSL https://raw.githubusercontent.com/nibtools/nibtools/main/nibpass/install.sh | bash -s -- --bin-dir /usr/local/bin

Workflow

Simple commands for daily use.

Create the vault

nibpass init
nibpass agent

Unlock once for the current session, or use --ttl for a shorter window.

Add accounts

nibpass add github --generate
nibpass add email --dialog
nibpass github add 2fa

2FA is added only when an account has it, so normal account creation stays short.

Use secrets

nibpass ls
nibpass show github
nibpass -c github
nibpass 2fa -c github

Clipboard copies are cleared after 30 seconds when the platform clipboard allows it.

Change safely

nibpass edit github
nibpass rotate master
nibpass git undo
nibpass audit

NibPass auto-commits successful changes so the vault has normal git history.

Security

Something you know plus something you have.

NibPass combines your master password with a local device key. Argon2id unlocks a random vault key, and account entries are encrypted with XChaCha20-Poly1305.

  • Git stores encrypted .nib files only.
  • The local device key stays outside the git-tracked vault.
  • The agent keeps the vault key in memory and expires automatically.
  • --no-agent forces a master-password prompt for high-risk use.

Backup

Bring passwords to another computer without trusting a service.

# first machine
nibpass sync init <private-git-repo>
nibpass recovery export ~/nibpass-recovery.key
nibpass sync
# new machine
git clone <private-git-repo> ~/.local/share/nibpass
nibpass recovery import ~/nibpass-recovery.key
nibpass agent
nibpass ls

Import

Move in from other password stores.

Import from Linux pass or CSV exports from common password managers and browsers. Imported records are re-encrypted into the native NibPass vault. 

nibpass import pass ~/.password-store
nibpass import bitwarden ~/Downloads/bitwarden.csv
nibpass import chrome ~/Downloads/chrome-passwords.csv
nibpass import apple ~/Downloads/passwords.csv
nibpass import firefox ~/Downloads/firefox-passwords.csv
nibpass import 1password ~/Downloads/1password.csv
